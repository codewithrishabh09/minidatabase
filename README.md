# MiniDatabase

A lightweight relational database engine built from scratch in C++20.

## Goal

The goal of MiniDatabase is to understand and implement the internal components of a relational database system.

## Planned Features

- SQL lexer
- SQL parser
- Query execution
- Table and schema management
- Page-based storage
- Disk manager
- Buffer manager
- B+ Tree indexing
- Transactions
- Write-Ahead Logging
- Concurrency

## Technology

- C++20
- CMake
- Git
- Local file storage
